# Obsidian 知识库治理 Bot

基于 [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 方法的 BotHarness 机器人，协助整理和维护 Obsidian 知识库。

- **导入**：保留原始资料，编写来源摘要，并将知识关联到主题、概念和实体页面。
- **问答**：先查知识库和相关来源，再给出带依据的回答，标明不确定性。
- **巡检**：检查断链、孤儿页、重复内容、来源缺失、矛盾和过期资料。
- **保护**：遵循用户授权；修改前备份，保留人工内容和 Obsidian 链接，来源冲突不静默覆盖。

在 DSH 的 Bot 市场粘贴本仓库地址安装。安装后选择要使用的知识库并按需授权工作区；仅安装机器人不会自动获得文件权限或开始治理。提示词是行为指引，实际能力取决于模型、工具和授权；使用前请阅读 [SOUL.md](SOUL.md)。
